# postgresql-student-management-queries
PostgreSQL Student Management System Assignment

PostgreSQL Assignment Solutions covering SQL fundamentals to intermediate concepts including SELECT, WHERE, ORDER BY, DISTINCT, LIKE, LIMIT, Aggregate Functions (COUNT, SUM, AVG, MAX, MIN), GROUP BY, HAVING, INNER JOIN, LEFT JOIN, and Multi-Table JOINs. This project demonstrates practical database querying using Students, Subjects, and Grades tables in a Student Management System database.

Topics Covered:
• Data Filtering and Sorting
• Pattern Matching with LIKE
• Aggregate Functions
• Grouping and Data Analysis
• HAVING Clause
• Table Joins (INNER JOIN, LEFT JOIN)
• Three-Table JOIN Operations
• SQL Query Optimization Basics

Tech Stack:
• PostgreSQL
• SQL
